## PEER-REVIEW-RUBRIC.md (consent is a hard dimension)

Score 1-5. **Accept only if mean >= 3, no dimension is 1, and Consent (C) is at least 3.** A 5 on schema with a 1 on consent is a reject.

| Dim | Name | 1 fail | 3 pass | 5 strong |
|-----|------|--------|--------|----------|
| C | Consent | Scrapes or publishes restricted material; no FPIC path | FPIC / veto named; no sacred samples | Written stop-rules, rehearsal vs authorized modes, destroy-notes path |
| P | Provenance | Unsourced "tradition says" | Sources or explicit rehearsal/dummy | Named public ethics docs + session log fields |
| A | Access | Anyone may dump the corpus | Classroom vs community vs public split | Access matrix hook (points at governance leaf) |
| R | Restricted content | Sacred text in the artifact | Handling table, no samples | Fail-states tested in facilitator notes |
| E | Education fit | Author-only ritual | Stranger can run a 30m session | Roles, timebox, pass option, a11y ticks |
| L | License honesty | Pretends community stories are CC-BY-NC-SA | Templates licensed; live output carved out | CONTRIBUTORS + community license note |
| D | Dual-use | Training-dump bait | Refuse scraping / doxxing | Concrete refuse + capture-pipeline gate |

Reviewer method (no author required):

1. Search the body for actual myth text, genealogies, GPS of sacred sites, or audio dumps. Any hit without a release line: fail C and R.
2. Confirm a consent / veto sentence exists.
3. Confirm license does not launder someone else's heritage.
4. Tick KIT-INDEX path.
5. Write 3-8 sentences. If C < 3, reopen.
